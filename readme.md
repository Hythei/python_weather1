# Python CLI Weather Project
## About
This is a rather simple Python project that I made to brush up on my Python skills and to see how MongoDB works with it.

It uses WeatherAPI to get the weather data, which can then be sent as a document to a MongoDB collection. It can do all the basic CRUD-operations, as long as the user knows the document's object ID.

## Status
Largely finished, but I will most likely improve the functions by separating the inputs from the database-related functions.
